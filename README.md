**SEO:** `canonical`, Open Graph `og:url`, Twitter `twitter:url`, `robots.txt`, `sitemap.xml` und alle JSON-LD-`@id`/`url`-Felder verwenden ausschließlich `https://beim-baecker-jos.webflow.io/`. `robots.txt` erlaubt die Indexierung (`Allow: /`). Die Seite setzt `index,follow`.

Änderungen im GitHub-Repository müssen separat auf dem Webflow-Hosting veröffentlicht werden.
